# Google ToDo リストを取り込む

Google の ToDo リスト（Google Tasks）を、AI WORK HUB のタスク一覧に取り込みます。
**読み取りだけ**です。こちらでの変更が Google に書き戻ることはありません。

このアプリはサーバーを持たない作りなので、ブラウザから直接 Google に繋ぎます。
そのため **クライアントシークレットは使いません**。必要なのはクライアントID 1つだけで、
これは秘密の値ではありません（ブラウザに出ます）。

## 1. Google Cloud で準備する

[Google Cloud Console](https://console.cloud.google.com/) で、以下を行います。

1. **プロジェクトを作る**（すでにあれば、それを使ってかまいません）
2. **「APIとサービス」→「ライブラリ」** で `Google Tasks API` を探し、**有効にする**
3. **「APIとサービス」→「OAuth 同意画面」**
   - User Type：**外部**
   - アプリ名・サポートメール・デベロッパー連絡先を入れる
   - スコープ：`https://www.googleapis.com/auth/tasks.readonly` を追加
   - **テストユーザー**に自分の Google アカウントを追加する
     （「公開」しなくてよい。テストユーザーのままで自分は使えます）
4. **「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuth クライアント ID」**
   - アプリケーションの種類：**ウェブ アプリケーション**
   - **承認済みの JavaScript 生成元** に、使う URL を入れる
     - `http://localhost:3000`（手元で動かす場合）
     - `https://<Vercel のドメイン>`（デプロイ先。パスは付けない）
   - 「承認済みのリダイレクト URI」は**空のままでよい**（この方式では使いません）
5. できた **クライアント ID**（`....apps.googleusercontent.com`）を控える

## 2. アプリに設定する

**Vercel の場合**

Project → Settings → Environment Variables に追加します。

| Key | Value |
| --- | --- |
| `NEXT_PUBLIC_GOOGLE_CLIENT_ID` | 控えたクライアントID |

追加したら **再デプロイ** してください（環境変数はビルド時に埋め込まれます）。

**手元で動かす場合**

リポジトリ直下に `.env.local` を作ります。

```
NEXT_PUBLIC_GOOGLE_CLIENT_ID=xxxxx.apps.googleusercontent.com
```

## 3. 使う

1. 「管理」画面を開く
2. 「外部連携」の **Google ToDo リスト** で「Google に接続する」を押す
3. Google の画面で許可する
4. 「いま取り込む」を押す

取り込んだタスクには「連携」の印が付きます。

## いつ取り込まれるか

既定では**自動**です。「管理」画面のチェックで切れます。

| きっかけ | 動き |
| --- | --- |
| アプリを開いたとき | 取り込む |
| 開いているあいだ | 10分ごとに取り込む |
| 別のタブから戻ったとき | 前回から5分以上経っていれば取り込む |
| アプリを閉じているあいだ | **動きません** |

サーバーを持たない作りなので、閉じているあいだは動きません。
ただ、閉じているときに最新である必要はありません。見るときに揃っていれば足ります。

Google 側が変わっていなければ何も起きないので、10分ごとに走っても
一覧が勝手に動くことはありません。取り込んだ結果は「管理」画面に
最終取り込みの時刻とともに残ります。

自動取り込みが失敗しても、画面には出しません（本来の「今日やること」が
埋もれるため）。理由を知りたいときは「いま取り込む」を押してください。

### Google Apps Script（GAS）ではだめなのか

だめです。GAS は Google のサーバーで動いて、どこかへ書き込む仕組みですが、
このアプリのデータはブラウザの中（localStorage）にあります。
GAS からブラウザの中へは書き込めないので、届け先がありません。

## 取り込みの決まりごと

勝手に増えたり戻ったりしないよう、次のように決めてあります。

- **押したときだけ取り込む。** 画面を開くたびに黙って増えることはありません
- **同じものを二重に作らない。** Google 側の id で照合します
- **Google 側が変わっていなければ、こちらは触らない。**
  こちらで完了にしたタスクが、取り込み直しで未着手に戻ることはありません
- **Google 側が変わっていれば、Google を正とする。**
  読み取り専用なので、食い違ったときは向こうに合わせます
- **Google 側で消えても、こちらでは消さない。**
  件数だけお知らせします。こちらで手を加えている可能性があるためです
- **自分で作ったタスクには一切触りません**

## 制限

- アクセストークンはメモリにしか置きません。画面を読み込み直すと接続し直しになります
  （一度許可していれば、確認画面は出ずに通ります）
- 期限は日付だけを取り込み、時刻は 18:00 に置きます
  （Google ToDo の期限は日付だけで、時刻を持たないため）
- 書き戻し（HUB → Google）はまだありません
